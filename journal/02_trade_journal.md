## D. 나의 실패노트 (누적)

실패분석팀이 매주 갱신한다. **같은 코드가 반복될수록 경고 등급이 올라간다.**

| 코드 | 누적 횟수 | 최근 발생일 | 관련 종목 | 누적 손실 | 재발 방지 규칙 |
|---|---|---|---|---|---|
| (아직 기록 없음) | | | | | |

2026-10-14 갱신: 10/6~10/8 매매 없음, 신규 실수 없음 (근거: 대표 답변 2026-10-14, 보유 없음·현금 100%). AI 팀 산출물 오류는 reports/work/2026-10-14/06_failure.md에 별도 정리.

**경고 등급**
- 1회: 기록만 한다.
- 2회: 🟡 주의 — 주간 리포트 맨 앞에 경고를 띄운다.
- 3회 이상: 🔴 위험 — 해당 유형의 매매를 1주일 쉬도록 권고하고, 재발 방지 규칙을 대표와 함께 새로 정한다.

## E. 나의 매매 규칙 (대표가 직접 고치는 곳)

처음엔 아래 예시로 시작하고, 실패노트가 쌓이면 대표가 직접 고친다.

1. A양식을 쓰지 않은 매수는 하지 않는다.
2. 한 종목 비중은 전체의 20%를 넘기지 않는다. (2026-10-05 대표 결정)
3. 손절 기준에 닿으면 이유를 찾지 말고 실행한다.
4. 하루에 10% 넘게 오른 종목은 그날 사지 않는다.
5. 손실 난 날에는 추가 매매를 하지 않는다.
6. 신용융자·미수를 쓰지 않는다. (2026-10-14 대표 결정)

## G. 실패분석팀 운영 규칙

1. 주간 리포트마다 지난주 매매를 B양식 기준으로 복기한다.
2. D표를 갱신하고, 🟡·🔴 경고는 리포트 맨 앞에 쓴다.
3. 이번 주 제안 종목이 과거 실수 패턴과 비슷하면 "과거 ○○ 실수와 유사"라고 명시한다.
4. 대표의 감정 점수가 4 이상인 매수가 반복되면 따로 지적한다.
5. 듣기 좋은 말보다 정확한 말을 우선한다.
