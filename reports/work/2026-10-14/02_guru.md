# 고수전략팀 주간 정리 (복기 대상 2026-10-05 ~ 10-09, 거래일 10/6~10/8)

- 리포트 날짜: 2026-10-14 (토요일 복기 2회차, 시험 가동 / 실제 요일은 수요일)
- 작성: 고수전략팀 / 평가 기준은 `docs/01_guru_principles.md`의 체크리스트와 25점 평가표뿐이다.
- 대표 상태: 보유 없음(현금 100%), 관심 종목 없음 (journal/02_trade_journal.md, 2026-10-14). 그래서 이번 임무는 "DART 5% 공시·국민연금 지분 변동에서 원칙에 맞는 신규 후보 최대 3개를 찾아 채점"이다.
- 이 문서는 매수·매도 의견을 내지 않는다. 점수, 근거, 반대 의견, 가치 함정 의심, 린치 유형만 적는다.
- 확인 방법 표기: **curl 원문** = Bash curl로 원문(JSON/HTML)을 직접 받아 읽음 / **검색 요약만** = 검색 요약 문장만 봄 / **미확인** = 열지 못함. 이 문서의 수치는 모두 curl 원문이다(검색 요약만 본 수치는 0건). 열지 못한 것은 "미확인"으로 6장에 모았다.

## 0. 결론 먼저

1. 최종 후보 3개를 25점 평가표로 채점했다. 셋 다 20점 미만이라 docs 기준으로는 **"관찰 목록"(15~19점)** 구간이다. 20점 이상(관심 종목 등록 검토)은 없다.

|---|---|---|---|---|---|

3. 점수가 낮게 나온 큰 이유는 **미확인 항목을 0점 또는 0.5점으로 처리**했기 때문이다(채점 규칙은 7장). 특히 ROE·흑자·배당의 "5년" 기준 중 2021~2022년 값을 열지 못했다. 6장 참고.
4. **"큰손이 샀다"는 조사 계기일 뿐이다.** 세 종목 모두 국민연금 공시는 7~9월 거래를 10/2에 일괄 접수한 후행 공시다. 특히 빙그레의 지분율 상승 3.28%p 중 일부는 회사가 주식을 소각해 발행주식 수가 줄어든 효과다(2장). 이 상황은 실패노트 M09(큰손 맹신)와 같은 위험이다. 대표는 현금 100%이고 코스피가 10/2 대비 -14.21%(10/14 6,008.81, 01_market.md) 빠진 구간이므로, 매수 전에 A양식을 쓰지 않는 매수는 M07(무계획 매수)이다(journal E규칙 1).

## 7. 채점 규칙 (docs 기준을 점수화한 방법)

docs/01_guru_principles.md의 체크리스트 항목만 쓴다. 항목마다 1(충족·확인됨), 0.5(부분 충족 / 5년 기준인데 3년만 확인 / 확인 범위 일부만 충족), 0(미충족 또는 미확인)을 주고, 관점별 평균으로 1~5점을 매겼다(90% 이상 5점, 70~89% 4점, 50~69% 3점, 30~49% 2점, 30% 미만 1점). 미확인은 "0점 처리"가 기본이고, 금융업 해당 없음 항목만 분모에서 뺐다. 이 환산표는 docs에 없는 이 문서의 작업 규칙이다(점수 → 20점/15점 구간은 docs 그대로).
