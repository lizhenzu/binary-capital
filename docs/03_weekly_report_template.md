# 03. 주간 리포트 양식

바이너리 자산운용의 주말 리포트 기준 문서.
토요일은 **지난주 돌아보기**, 일요일은 **다음 주 준비**로 역할을 나눈다. 내용이 겹치지 않게 쓴다.

공통 규칙
- 결론 먼저, 근거는 뒤에.
- 모든 수치에 기준 날짜와 출처를 적는다. 확인 안 된 것은 "미확인".
- 전체 분량은 A4 3~4장 이내. 대표가 15분 안에 읽을 수 있게.
- 주식 용어는 처음 나올 때 괄호로 쉽게 풀이한다.

---

## 📘 토요일 리포트 — "지난주 복기"

### 0. 실패분석팀 경고 (해당 시 맨 앞)
- 🔴/🟡 경고가 있으면 코드, 횟수, 관련 매매를 먼저 쓴다. 없으면 "이번 주 경고 없음".

### 1. 한 줄 요약
- 지난주 시장과 대표 매매를 한 문장으로.

### 2. 시장분석팀 — 지난주 시장 정리
| 항목 | 지난주 | 변화 | 한 줄 해석 |
|---|---|---|---|
| 코스피 | | | |
| 코스닥 | | | |
| 원/달러 환율 | | | |
| 외국인 순매수(코스피) | | | |
| 기관 순매수(코스피) | | | |
- 강했던 업종 3개 / 약했던 업종 3개와 이유

### 3. 고수전략팀 — 큰손 동향
- 지난주 DART 대량보유(5%) 공시 중 눈에 띄는 것 (보유 목적 포함)
- 국민연금·가치투자 운용사 지분 변동
- 내부자(임원·대주주) 매수·매도
- 각 항목마다 "따라하기 함정" 한 줄

### 4. 실패분석팀 — 대표 매매 복기
- 지난주 매매 목록과 B양식 복기
- 계획대로 한 매매 / 어긋난 매매
- 실패노트 D표 갱신안 (대표가 지식 파일에 붙여넣을 수 있게 표로)

### 5. 실패분석팀 — 외부 사례 1~2건
- 지난주 국내 투자 성공 또는 실패 사례를 F양식으로
- "우리 회사가 배울 점" 한 줄

### 6. 대표에게 드리는 질문 1개
- 복기를 위해 대표가 생각해 볼 질문 하나.

## 📗 일요일 리포트 — "다음 주 준비"

### 1. 한 줄 요약
- 다음 주 시장 분위기와 핵심 관전 포인트 한 문장.

### 2. 시장분석팀 — 다음 주 일정
- 주요 경제지표 발표, 금리 결정, 실적 발표, 공모주·보호예수 해제, 옵션 만기 등
| 날짜 | 일정 | 영향 받을 업종·종목 |
|---|---|---|

### 3. 예측분석팀 — 다음 주 시나리오
| 시나리오 | 조건(이러면) | 예상 흐름 | 대응 |
|---|---|---|---|
| 낙관 | | | |
| 기본 | | | |
| 비관 | | | |
- 확률 숫자 대신 근거를 쓴다.

### 4. 고수전략팀 — 관심 종목 (최대 3개)
종목마다:
- 25점 종합 평가표 (01 문서 7장)
- 린치 6유형 분류
- 왜 지금 볼 만한가 (3문장 이내)
- 반대 의견: 이 종목을 사면 안 되는 이유 (반드시 작성)

### 5. 트레이딩전략팀 — 실행 계획
| 종목 | 매수 검토 조건 | 분할 계획 | 손절 기준 | 목표 기준 | 권장 최대 비중 |
|---|---|---|---|---|---|
- "지금 사라"가 아니라 "이 조건이 되면 검토"로 쓴다.

### 6. 리스크관리팀 — 점검
- 현재 보유 종목 비중 쏠림 여부 (대표 보유 현황을 알고 있을 때)
- 관심 종목이 과거 실수 코드와 겹치는지
- 다음 주 피해야 할 행동 1가지

### 7. 이번 주 대표 체크리스트
- [ ] 매수 전 A양식 작성
- [ ] 손절 기준 미리 입력
- [ ] (이번 주 맞춤 항목 1개)
