# 01. 고수 투자철학 — 국내 시장 적용판

바이너리 자산운용 고수전략팀의 기준 문서. 종목 분석 시 이 문서의 체크리스트로 평가한다.

---

## 1. 워렌 버핏 — "좋은 회사를 적당한 가격에"

**핵심 원칙**
- 이해할 수 있는 사업에만 투자한다.
- 경쟁사가 쉽게 따라올 수 없는 '경제적 해자'(브랜드, 독점력, 전환비용, 원가 우위)가 있어야 한다.
- 자본을 효율적으로 쓰는 회사(높고 꾸준한 ROE)를 고른다.
- 내재가치보다 충분히 싸게 산다(안전마진).
- 좋은 회사는 오래 보유한다.

**국내 적용 체크리스트**
| 항목 | 기준 |
|---|---|
| 사업 이해도 | 대표가 3문장으로 설명할 수 있는가 |
| ROE | 최근 5년 평균 10% 이상, 들쭉날쭉하지 않은가 |
| 부채비율 | 100% 이하(금융업 제외) |
| 해자 | 국내 점유율 1~2위, 가격 인상력이 있는가 |
| 주주환원 | 배당 꾸준함, 자사주 매입 후 소각 여부 |
| 지배구조 | 대주주 일가 리스크, 물적분할·쪼개기 상장 이력 |

**국내 주의점:** 국내는 지배구조 할인(코리아 디스카운트)이 커서, 숫자가 좋아도 주주를 배려하지 않는 회사는 오래 저평가될 수 있다.

---

## 2. 벤저민 그레이엄 — "싸게 사서 손해 보지 않기"

**핵심 원칙**
- 시장(미스터 마켓)의 변덕에 휘둘리지 말고 이용하라.
- 가치보다 훨씬 싼 가격에 사서 실수해도 손해를 줄인다.

**국내 적용 체크리스트**
| 항목 | 기준 |
|---|---|
| PER | 업종 평균보다 낮은가 |
| PBR | 1배 미만인가 |
| 흑자 지속 | 최근 5년 연속 흑자 |
| 배당 | 최근 5년 배당 지급 |
| 유동비율 | 150% 이상 |

**국내 주의점:** 국내에는 PBR 1배 미만 종목이 매우 많다. 싸기만 하고 오르지 않는 '가치 함정(밸류 트랩)'을 피하려면, 주가가 오를 계기(실적 개선, 주주환원 강화, 지배구조 개선)가 있는지 반드시 함께 본다.

---

## 3. 피터 린치 — "아는 것에 투자하라"

**핵심 원칙**
- 생활 속에서 먼저 발견한 회사를 조사한다.
- 성장률 대비 PER(PEG)로 비싼지 싼지 판단한다.
- 종목을 6가지 유형으로 나누고, 유형마다 기대치와 매도 기준을 다르게 둔다.

**6가지 유형과 국내 예시 유형**
| 유형 | 특징 | 매도 신호 |
|---|---|---|
| 저성장주 | 성숙 산업, 배당 위주 | 배당 축소 |
| 대형우량주 | 연 10% 내외 성장 대기업 | 30~50% 상승 후 재평가 |
| 고성장주 | 연 20% 이상 성장 중소형주 | 성장률 둔화 |
| 경기순환주 | 반도체·화학·철강·해운 등 | 업황 고점 신호(재고 증가, 가격 하락) |
| 회생주 | 위기 후 회복 중 | 회복 완료 |
| 자산주 | 보유 부동산·지분 가치가 시가총액보다 큼 | 자산 가치 반영 |

**국내 적용 체크리스트**
- PEG = PER ÷ 이익성장률(%) → 1 이하면 매력, 2 이상이면 비쌈
- 이 종목은 6가지 중 어디에 속하는가? (유형을 정하지 못하면 투자하지 않는다)
- "이 회사를 왜 샀는지" 2분 안에 말할 수 있는가

**국내 주의점:** 국내 대표 업종 다수가 경기순환주다. 경기순환주를 고성장주로 착각해 업황 고점에서 PER이 낮아 보일 때 사는 실수를 경계한다.

---

## 4. 필립 피셔 — "탁월한 성장 기업을 찾아 오래 보유"

**핵심 원칙(15가지 중 핵심 요약)**
- 몇 년간 매출이 크게 늘 제품·시장이 있는가
- 연구개발에 꾸준히 투자하는가
- 이익률이 업계 평균보다 높은가
- 경영진이 정직하고 장기적 관점을 가졌는가
- 나쁜 소식도 숨기지 않고 공개하는가

**국내 적용 체크리스트**
- 매출 대비 연구개발비 비율 추이
- 영업이익률이 동종업계 대비 높은가
- IR·공시 태도: 실적 부진 때도 설명하는가
- 경영진의 자사주 매도 이력

---

## 5. 국내 "큰손" 따라하기 — 공개 데이터 추적법

버핏 같은 해외 고수는 국내 주식을 거의 보유하지 않으므로, 국내에서는 공개된 큰손의 움직임을 추적한다.

**추적 대상과 출처**
| 대상 | 확인처 | 볼 것 |
|---|---|---|
| 5% 이상 대량보유자 | DART(전자공시) 대량보유 상황보고서 | 보유 목적(단순투자/일반투자/경영참가), 지분 증감 |
| 국민연금 | DART 공시, 국민연금 기금운용 공개 자료 | 지분 신규 편입·확대·축소 종목 |
| 가치투자 운용사 | DART 대량보유 공시 | 어떤 종목을 새로 담았는가 |
| 외국인·기관 수급 | 증권사 HTS/MTS, 한국거래소 | 연속 순매수·순매도 종목 |
| 내부자 | DART 임원·주요주주 소유상황보고서 | 경영진의 자사주 매수·매도 |

**따라하기 함정(반드시 함께 보고할 것)**
- 공시는 늦다. 큰손은 이미 사고 난 뒤다.
- 그들의 매수 가격과 매수 이유를 우리는 모른다.
- 그들은 분산된 큰 포트폴리오의 일부로 산 것이지, 한 종목에 몰빵한 것이 아니다.
- 그들이 언제 파는지도 늦게 안다.
- 따라서 "큰손이 샀다"는 **조사를 시작할 계기**일 뿐, 매수 이유가 아니다.

## 6. 국내 시장의 특성 (모든 팀 공통 참고)

- 지수가 오랜 기간 박스권에 머무는 경향이 있어, 무작정 장기 보유보다 가격 규율이 중요하다.
- 테마주(정치·신기술·이슈) 급등락이 잦다. 테마주는 고수전략팀 분석 대상에서 제외한다.
- 시가총액 상위 일부 업종(반도체 등)의 비중이 커서 지수가 특정 업종에 크게 좌우된다.
- 환율, 미국 금리, 외국인 수급의 영향을 크게 받는다.
- 물적분할, 유상증자, 쪼개기 상장 등 소액주주에게 불리한 이벤트를 늘 확인한다.

## 7. 종합 평가표 (리포트 작성 시 사용)

종목마다 아래 표를 채운다. 각 항목 5점 만점.

| 관점 | 점수(1~5) | 한 줄 근거 |
|---|---|---|
| 버핏(해자·ROE·주주환원) | | |
| 그레이엄(저평가·안전마진) | | |
| 린치(유형·PEG) | | |
| 피셔(성장성·경영진) | | |
| 큰손 동향(공시·수급) | | |
| **합계 (25점)** | | |

- 20점 이상: 관심 종목 등록 및 진입 조건 검토
- 15~19점: 관찰 목록
- 14점 이하: 제외

점수는 판단을 돕는 도구일 뿐이며, 실패노트에 기록된 과거 실수와 겹치면 점수와 관계없이 경고한다.
